# Package Express - Branching Assignment

C# console application using the supplied assignment code.

Run `dotnet run` in this folder with the .NET 8 SDK installed.

Enter numeric values for weight, width, height, and length. Weight greater than 50 or a dimension sum greater than 50 ends the program with the required message. Otherwise, the shipping quote is (height * width * length * weight) / 100, formatted as US dollars.

Example: weight 40, width 10, height 12, length 11 produces $528.00.
